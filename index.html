DataMHS

DataMHS adalah aplikasi mobile untuk menampilkan dan mengelola informasi data mahasiswa.

Aplikasi ini menggunakan Firebase Authentication untuk login melalui akun Google dan Cloud Firestore untuk menyimpan serta menampilkan data mahasiswa.

Fitur aplikasi

  • Login menggunakan akun Google.
  • Menampilkan daftar mahasiswa.
  • Mengakses informasi mahasiswa.
